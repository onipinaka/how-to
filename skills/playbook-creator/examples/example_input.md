# Example Input

This is an example of inputs that would trigger the Playbook Creator skill.

---

## Option A: Feed it a PRD

> Create a playbook for this PRD

Then paste or reference the PRD document generated by the PRD Creator skill. The Playbook Creator will analyze every section and generate sequential build prompts covering the full scope.

---

## Option B: Feed it a concept directly

> Give me step-by-step copy-paste prompts to build an AI-powered meal planning app with:
> - User authentication (email + Google OAuth)
> - Preference quiz for dietary restrictions and goals
> - AI meal plan generation using OpenAI
> - Automatic grocery list creation
> - Stripe billing for premium plans
> - Dashboard with weekly plan view
>
> Tech stack: Next.js 14, TailwindCSS, Supabase, Stripe

---

## Option C: Minimal input

> Spoon-feed me micro-prompts to build a task management app for small teams

Even with minimal input, the Playbook Creator will infer a full scope and generate 20-40+ sequential build prompts with sensible defaults.
