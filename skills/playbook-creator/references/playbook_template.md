# Playbook Template Reference

This reference file provides a quick-reference checklist of all mandatory phases, prompt density requirements, and quality rules for playbooks generated by the `playbook-creator` skill.

---

## Mandatory Playbook Phases (All Required)

| Phase | What It Contains | Minimum Prompts |
| :--- | :--- | :--- |
| **Tool Matrix** | Table assigning AI tool + model to every task category | 1 full table |
| **Phase 1: Scaffolding** | Directory creation, framework init, design system, env vars | 4 prompts |
| **Checkpoint 1** | Verify dev server starts cleanly | 1 debug prompt |
| **Phase 2: UI Components** | Button, Input, Card, Modal, Skeleton, Badge, Navbar, Footer, Sidebar, Hero, Features, Pricing, Testimonials, FAQ, Assembly | 10-15 prompts |
| **Checkpoint 2** | Verify landing page renders | 1 debug prompt |
| **Phase 3: Auth & Database** | Supabase setup, client helpers, SQL migration, middleware, login page, signup page | 5-6 prompts |
| **Checkpoint 3** | Verify auth flow end-to-end | 1 debug prompt |
| **Phase 4: Dashboard & CRUD** | Layout shell, dashboard home, list page, create/edit form, detail page | 5 prompts |
| **Checkpoint 4** | Verify CRUD works | 1 debug prompt |
| **Phase 5: Settings & Billing** | Settings layout, profile page, Stripe API routes, billing page | 4 prompts |
| **Phase 6: Audit & Deploy** | TypeScript check, accessibility audit, production deployment | 3 prompts |

**Total minimum: 20-40 sequential prompts + 4 checkpoint prompts.**

---

## Prompt Format Rules

Every copy-paste prompt block must follow this format:

```
### Step X.Y: [Human-readable task name]
**Tool**: [AI Tool Name] | **Model**: [Model Name]

\`\`\`text
PROMPT X.Y: [UPPERCASE TITLE]
--------------------------------------------------
Context: [What was already built in prior steps that this prompt depends on.]

[Full, specific, actionable instructions. No brackets. No placeholders. Exact filenames. Exact component names. Exact behavior descriptions.]
\`\`\`
```

---

## Anti-Patterns to Reject
- ❌ Bracket placeholders: `[Detailed prompt for...]`, `[Core action]`, `[Add specifics]`
- ❌ Bundled mega-prompts: "Build the entire dashboard with sidebar, content, and all pages"
- ❌ Generic SaaS patterns when the product is a different domain
- ❌ Missing context lines (prompts that don't reference prior work)
- ❌ No checkpoints between phases
- ❌ Application source code written directly in the playbook
- ❌ Fewer than 20 total prompts for a standard app
