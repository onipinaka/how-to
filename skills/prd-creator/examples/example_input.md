# Example Input

This is an example of a minimal input that would trigger the PRD Creator skill.

---

## Minimal Input (2 lines)

> Create a PRD for an AI-powered meal planning app that generates personalized weekly meal plans and automatic grocery lists based on dietary preferences, allergies, and budget constraints.

---

## Medium Input (5-10 lines)

> Create a PRD for a project management tool for small creative agencies.
>
> Core features:
> - Kanban boards with drag-and-drop
> - Time tracking per task
> - Client portal where clients can view project progress and leave feedback
> - Invoice generation from tracked hours
> - Team workload visualization
> - Integrations with Figma and Slack
>
> Target audience: Creative agencies with 5-30 employees.
> Monetization: SaaS with free trial, then $15/user/month.

---

Both inputs above will produce the **same depth of PRD output** — the skill infers all missing details (tech stack, auth system, billing, edge cases, etc.) and lists assumptions explicitly.
