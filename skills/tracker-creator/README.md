# Tracker Creator

Act as an AI Project Manager. This skill reads a PRD and Playbook and generates a living, interactive Markdown Execution Tracker.

## Features
- Extracts 100% of the prompts from a playbook and turns them into a checklist.
- Generates a high-level progress dashboard.
- Includes metadata fields for Status, Assignee, Tool, and Notes on every task.
- Creates a Blocker Log for tracking issues.

## How to use

1. Ensure you have already generated a PRD and Playbook.
2. Ensure the skill is installed in your project.
3. Ask your AI tool:
   > "Create a tracker for the [app name] playbook"
4. The AI will output a `tracker_[name].md` file. You can then check off boxes (`[x]`) as you complete tasks!
